企業庫存對帳與訂單檔案庫

任職食品批發物流業者期間，將日常出貨、庫存扣帳、異動備註與 LINE 訂單訊息整理成可稽核、可查詢、可重算的營運工具。

Google Apps Script Google Sheets 正則解析 FIFO 扣帳 訂單編號配對率 99.7%
查看去識別原始碼 查看 README

系統做什麼

每日自動扣帳讀取出貨明細，依到期日 FIFO 分批扣除庫存。
多種異動處理自動分類一般出貨、退貨入庫、換貨抵銷、司機回庫與補貨。
訂單檔案庫解析 LINE 群組訊息，建立可查詢的訂單紀錄並提升追蹤效率。

技術重點

  • 以正則表達式解析中文手寫備註，判斷加扣方向與異動類型。
  • 使用不可見字元標記系統備註與人工備註，避免重算時覆蓋使用者輸入。
  • 支援跨日重算、一鍵補正、稽核標色、每週報表、快過期與低庫存提醒。
  • 公開版本已移除客戶、店家、商品與內部編號，保留程式架構供作品集展示。
