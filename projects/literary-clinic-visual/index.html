Exhibition Visual / Design Automation

展覽視覺程式化生成系統

為「情緒診療室 — 閱讀處方總覽展」製作的視覺生成流程，把文案、版型、圖片處理與輸出規格整理成可一鍵重跑的系統。

Node.js Playwright HTML Canvas SVG / PDF / PNG Figma-ready Assets

成果預覽

文案與書單內容為展覽方所有，此頁展示我負責的視覺生成成果；生成腳本含展覽內容，因此不公開原始碼。

我做了什麼

資料驅動版型13 張處方箋卡片由同一份資料源產生，修改資料即可重新輸出全部成品。
多格式輸出一鍵產出社群／列印 PNG、可編輯向量 PDF、SVG 與 HTML 原始版型。
非工程師交付提供雙擊執行的批次檔、中文操作說明與 Figma 匯入指引。

技術重點

  • 以 Playwright 驅動無頭瀏覽器渲染 Canvas／HTML 版型，再依用途輸出不同格式。
  • 用程式完成照片灰階、曲線調整、45° 圓點網屏半調、拍立得邊框、陰影與復古桌面合成。
  • 處理長短不一的內文，自動計算段落高度與斷行，降低文字溢出或截斷風險。
