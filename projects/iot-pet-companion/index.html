IoT 寵物陪伴系統

以 Raspberry Pi 作為硬體核心，整合感測器、馬達、Flask REST API 與 Flutter App，完成遠端控制、自動避障與即時影像串流的畢業專題。

Raspberry Pi Flask REST API Flutter App GPIO / Motor Control MJPEG Streaming
GitHub Demo 簡報

作品重點

硬體整合以 Raspberry Pi 串接感測器與馬達，處理移動、避障與設備控制。
後端 API使用 Flask 建立 RESTful API，讓 App 可以遠端下指令並取得設備狀態。
跨平台 App以 Flutter 製作控制介面，支援遠端操作與即時影像查看。

我負責的內容

  • 規劃系統架構與資料流程，讓硬體、後端與 App 可以穩定串接。
  • 實作遠端操控、自動避障與 MJPEG 即時影像串流。
  • 進行硬體控制、連線測試與整體除錯，整理成可展示的畢業專題成果。
